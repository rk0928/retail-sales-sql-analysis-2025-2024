# Retail Sales SQL Analysis (2024–2025)

## Overview
This project analyzes retail sales performance between 2024 and 2025 using SQL, Excel, and CSV datasets. The goal was to identify sales trends, compare year-over-year performance, and demonstrate practical SQL querying and business analysis skills using real-world style sales data.

## Tools Used
- SQL
- MySQL Workbench
- Excel
- CSV Data Imports
- Data Visualization

## Skills Demonstrated
- Creating structured datasets
- Importing CSV files into SQL environments
- Writing SQL queries
- Aggregating and filtering data
- Year-over-year sales analysis
- Business trend analysis
- Data visualization and reporting
- Translating data into business insights

## Files Included
- `full_sql_analysis.sql`
- `sales_2024_2025.csv`
- `sales_2024_2025.xlsx`
- `results_summary.md`

## Key Business Questions
1. What were total sales by year?
2. Which months showed the strongest sales performance?
3. How did 2025 compare to 2024?
4. What trends appeared across the dataset?
5. What business insights could be identified through SQL analysis?

## Summary
This project demonstrates foundational SQL and analytical skills through real-world style retail sales analysis, reporting, and data interpretation.
